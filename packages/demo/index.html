How a payment settles

1Charge opened on Flare, priced by FTSOv2
2Payer sends native XRP with the charge's destination tag
3FDC XRPPayment attests it — tag, amount, sender
4FlarePayEscrow.settle(proof) releases the goods

Trustless

  • Payment existence, amount, tag (FDC proof, verified on-chain)
  • USD→XRP conversion (FTSOv2, pinned at charge time)
  • Release conditions (contract code, replay-guarded)

Not trusted

  • This server — it only relays proofs; anyone can submit them
  • Custody — funds go payer → merchant on XRPL, never through us

Same rail, for AI agents (x402)

Flare's own x402 guide is blocked on FXRP gaining EIP-3009. FlarePay settles a proof of a native XRP payment instead — so it works today, and the agent needs no EVM wallet and no gas.

                "settlement": "flare-fdc-xrppayment" }] }
