The whole integration

// 1. sell a pack — one call to FlarePay
POST /api/charges
{ "usdCents": 1000,
  "metadata": "750 credits" }

→ { id, xrpAmount, destinationTag,
    checkoutUrl }
// 2. grant on the signed webhook
X-FlarePay-Signature: sha256=…

{ "event": "charge.paid",
  "charge": { "id": "22",
    "votingRound": 1421448 } }

// credits += pack.credits
// 3. serve the product — no proof here
POST /v1/forecast
→ 200 { forecast, remaining: 749 }

// settlement already happened.
// this path never touches Flare.

Kelvin never holds a private key, never runs an XRPL node, and never takes custody. The payment goes payer → Kelvin directly; Flare only proves it.
